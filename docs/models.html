Core workflow / model

Model development

JimmyModel keeps architecture, optimization, and phase-specific step logic together while exposing named losses and outputs to the trainer.

The step contract

MethodResponsibilityReturn value
forward(...)Pure network computation.Model-defined tensors.
trainStep(batch)Forward pass, loss calculation, and backwardOptimize.(loss_dict, output_dict)
evalStep(batch)Validation computation and optional figure output.(loss_dict, output_dict)
testStep(batch)Test behavior; the base implementation delegates to evalStep.(loss_dict, output_dict)
Main loss keys are operational contracts.JimmyTrainer schedules from Train/Main and selects the best checkpoint from Eval/Main. Both must be present in the corresponding declared name lists and returned dictionaries.

Minimal implementation

import torch
import torch.nn as nn
from Models import JimmyModel, getAutoCast


class Regressor(JimmyModel):
    def __init__(self, width: int = 64, **model_kwargs):
        super().__init__(**model_kwargs)
        self.train_loss_names = ["Train/Main"]
        self.eval_loss_names = ["Eval/Main"]
        self.network = nn.Sequential(nn.Linear(8, width), nn.GELU(), nn.Linear(width, 1))
        self.loss = nn.MSELoss()

    def forward(self, features):
        return self.network(features)

    def trainStep(self, batch):
        with getAutoCast(batch["features"], self.mixed_precision):
            prediction = self(batch["features"])
            loss = self.loss(prediction, batch["labels"])
        self.backwardOptimize(loss)
        return {"Train/Main": loss.item()}, {"prediction": prediction.detach()}

    def evalStep(self, batch):
        with torch.no_grad():
            prediction = self(batch["features"])
            loss = self.loss(prediction, batch["labels"])
        return {"Eval/Main": loss.item()}, {"prediction": prediction.detach()}

Call initialize() after moving the model to its device. This creates the optimizer and, when requested, compiles the bound forward method.

Optimization controls

Mixed precision

Set mixed_precision=True and wrap computation with getAutoCast. backwardOptimize owns gradient scaling.

Gradient clipping

Set clip_grad above zero to clip the model's gradient norm after unscaling.

Compilation

Set compile_model=True to request module compilation through self.compile() during initialization.

Optimizer access

The configured optimizer is created by initialize(); lr returns the first parameter group's learning rate.

Checkpoint behavior

saveTo(path) writes the model state dictionary. loadFrom(path) loads compatible parameters, reports missing or unexpected keys, and skips size-mismatched tensors rather than forcing them into the model.

A partial load is still a partial load.Read the reported key differences and confirm that skipped tensors are intentional before resuming research.
