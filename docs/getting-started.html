Getting started

Run the included MNIST example, understand what it creates, and then replace its dataset and model with your own.

Requirements

JimmyTorch is currently used directly from its source checkout; this repository does not define a packaged release or pinned dependency manifest. Use a Python environment with PyTorch and install the modules required by the feature set you use.

AreaRuntime modules
Repository importstorch, torchvision, pandas, matplotlib, rich, jaxtyping, tqdm, numpy, numpy-stl, plotly, calflops, aiohttp
Optional integrationstensorboard when enabled; psutil and pynvml for monitor system metrics
Install PyTorch for your platform first.CUDA wheels and accelerator support vary by operating system and hardware; follow the official PyTorch installation selector rather than copying an environment-specific command.

The current umbrella imports expose 3D and cost-analysis modules eagerly, so numpy-stl, plotly, and calflops are required even if the first experiment does not call those helpers.

python -m pip install torchvision pandas matplotlib rich jaxtyping tqdm \
  numpy numpy-stl plotly calflops aiohttp

1. Get the source

git clone https://github.com/JinmingWang/JimmyTorch.git
cd JimmyTorch

Run entry scripts from the repository root so imports such as from Models import ... and the default Runs/ path resolve correctly.

2. Start the optional monitor

Start one standalone service for the working directory. It serves the dashboard and reads the run tree under ./Runs.

python -m Training.ExperimentManager

Open http://127.0.0.1:9000. To choose another run directory or starting port:

python -m Training.ExperimentManager \
  --runs-root /path/to/project/Runs \
  --host 127.0.0.1 \
  --port 9000
The service is optional.Training writes its SQLite record locally and continues if the HTTP service is absent or temporarily unreachable.

3. Run the included experiment

python main.py

The sample downloads MNIST through torchvision, trains SampleCNN, then evaluates the best checkpoint. It therefore needs network access on its first run and may use the detected CUDA device.

4. Inspect the run

Runs/
└── MNISTSampleDataset/
    └── SampleCNN/
        └── sample_cnn_baseline/
            ├── best.pth
            ├── last.pth
            ├── comments.txt
            ├── model_arch.txt
            └── status_and_log.sqlite

TensorBoard event files are added only when enable_tensorboard is true. The SQLite file is the Experiment Manager's durable record for metadata, scalars, and figures.
