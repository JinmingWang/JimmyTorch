Core workflow / orchestration

Training and evaluation

JimmyExperiment assembles a dataset, model, optimizer, scheduler, trainer, and run record. JimmyTrainer executes the batch loop and checkpoint policy.

Configure an experiment

import torch
from JimmyExperiment import JimmyExperiment
from Datasets import MyDataset
from Models import MyModel


experiment = JimmyExperiment(
    comments="Baseline with normalized inputs",
    dir_name="baseline-v1",
)

experiment.dataset_cfg.cls = MyDataset
experiment.dataset_cfg.add(batch_size=64, drop_last=False, shuffle=True)

experiment.model_cfg.cls = MyModel
experiment.model_cfg.add(
    optimizer_cls=torch.optim.AdamW,
    optimizer_args={"lr": 2e-4, "weight_decay": 1e-4},
    mixed_precision=True,
    compile_model=False,
    clip_grad=1.0,
)

experiment.lr_scheduler_cfg.cls = torch.optim.lr_scheduler.ReduceLROnPlateau
experiment.lr_scheduler_cfg.add(mode="min", factor=0.5, patience=10)

experiment.constants.update({
    "n_epochs": 100,
    "moving_avg": 100,
    "eval_interval": 1,
    "experiment_manager_server_port": 9000,
    "enable_tensorboard": False,
})

trainer = experiment.start()

DynamicConfig stores a target class plus public attributes. build() passes those attributes as keyword arguments to the current cls; use add(**kwargs) or attribute assignment to update them and remove(key) to delete one.

What start() does

01

Build

Builds the same dataset configuration twice with set_name changed to train and eval.

02

Initialize

Moves the model to DEVICE, optionally loads a checkpoint, initializes its optimizer, then builds the scheduler.

03

Record and train

Creates run paths and metadata, builds the selected trainer class, runs it synchronously, and returns it when training ends.

Experiment constants

KeyDefaultMeaning
n_epochs100Maximum number of epochs.
moving_avg100Window for reported training losses.
eval_interval1Evaluate and save checkpoints when the zero-based epoch index is divisible by this value.
save_dirNoneBase checkpoint directory; the run name is appended when supplied.
log_dirNoneBase log directory; defaults to the resolved save directory.
experiment_manager_server_port9000Port to which the training-side client reports.
enable_tensorboardFalseCreate TensorBoard events alongside the SQLite run record.

Additional JimmyTrainer options—including early_stop_lr, progress_show_recent_steps, progress_refresh_interval, and progress_host—can be added to experiment.constants.

Loop, scheduler, and checkpoint policy

  • Every epoch wraps the training dataset in MultiThreadLoader(queue_size=3).
  • Returned training losses are smoothed for reporting with one MovingAvg per declared name.
  • The scheduler's compatible update function receives the smoothed Train/Main value after each epoch.
  • Evaluation calls model.evalStep for each validation batch and averages every declared evaluation loss.
  • On evaluation epochs, best.pth is updated when Eval/Main improves and last.pth is overwritten.
  • Training stops early when early_stop_lr > 0 and the current learning rate falls below it.
“Last” means the last evaluation checkpoint.If eval_interval is greater than one, last.pth is not written after every epoch.

Resume and test

# Load model state before the optimizer is created.
trainer = experiment.start("Runs/.../last.pth")

# Test independently; the result has one row per test batch.
test_set = experiment.dataset_cfg.build()
report = experiment.test(trainer.model, test_set)
report.to_csv("test-report.csv", index=False)

JimmyExperiment.test() calls model.testStep and returns a pandas DataFrame containing each declared evaluation metric per batch.

Custom trainers

Assign a compatible class to experiment.trainer_type when a task needs a different training paradigm. It receives the built train/eval datasets, model, scheduler, resolved directories, experiment constants, and ExperimentLogger. Preserve the local logging and close/error lifecycle when replacing the default trainer.
