Generated convolution blocks

Models.Basics exposes 1D and 2D pre-/post-activation combinations using BatchNorm (Bn), InstanceNorm (In), or GroupNorm (Gn) with ReLU, LeakyReLU, GELU, or SiLU. Post-activation names follow Conv{1D|2D}{Norm}{Activation}; pre-activation names follow {Norm}{Activation}Conv{1D|2D}.

clean_timestep-1Explicit clean-data endpoint after schedule index 0.

Discrete schedules are linear, quadratic, log, or cosine. Discrete prediction callbacks return exactly one of x0_pred, accumulated epsilon_0_to_t_pred, or v_pred in a three-item tuple. Single-step noise is named epsilon_t_to_tp1; accumulated noise uses epsilon_0_to_t or epsilon_0_to_tp1. Score-SDE callbacks instead return a score tensor from (noisy_samples, continuous_timesteps, **kwargs). See Specialized utilities for equations, examples, migration notes, and references.

Distributed API

The Distributed package exports DistributedJimmyModel, DistributedJimmyDataset, DistributedJimmyTrainer and DistributedJimmyExperiment. The experiment retains model_cfg, dataset_cfg, lr_scheduler_cfg, constants, start(checkpoint=None) and test(model, test_set), adding distributed_cfg. For manual lifecycles import DistributedContext from Distributed.Context, construct it before CUDA objects, and close it in a finally block. No distributed arguments are added to legacy classes.
