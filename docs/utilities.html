Specialized utilities

JimmyTorch includes focused helpers for diffusion processes, geospatial trajectories, general sequences, and sliced 3D geometry.

DDPM and DDIM

DiffusionModels exports two schedule/process objects. Both support linear, quadratic, and logarithmic beta schedules; both accept predictions of x0, noise epsilon, or velocity v during denoising.

import torch
from DiffusionModels import DDIM

process = DDIM(
    min_beta=1e-4,
    max_beta=2e-3,
    max_diffusion_step=100,
    device="cpu",
    scale_mode="linear",
    skip_step=5,
)

x0 = torch.randn(4, 32)
t = torch.tensor([10, 20, 30, 40])
noise = torch.randn_like(x0)
xt = process.diffuse(x0, t, noise)
velocity = process.computeVelocity(x0, noise, t)

Trajectory utilities

Trajectory helpers operate on a single (L, 2) tensor or batched (B, L, 2) tensors where documented. The two coordinates are longitude and latitude for geographic distance functions.

CoordinatesgetLng, getLat, computeDistanceExtract axes and sum pairwise coordinate-space distances.

Coordinate-space and geographic distance differ.computeDistance sums Euclidean segment lengths in the tensor's coordinate units. Use geometricDistance for longitude/latitude distance in metres.

General sequences

cropPadSequence(seq, target_len, pad_value=0.0) crops or pads along the first dimension and preserves the remaining feature dimensions. Unlike cropPadTraj, it is not restricted to two-coordinate trajectories.

3D mesh and slicing pipeline

The utilities in Datasets.ThreeDUtils form a geometry preprocessing pipeline:

01

Load and normalize

loadSTL, loadOFF, loadOBJ, or ASCII-only loadPLY, followed by normalizeMesh.

02

Slice and project

meshSlicing or meshSlicing_vectorized intersects triangle meshes with planes; projection helpers map intersections into 2D.

03

Rasterize or inspect

computeSDFImages creates signed-distance grids; build_figure produces an interactive Plotly view.

import torch
from Datasets.ThreeDUtils import (
    loadOBJ, normalizeMesh, meshSlicing,
    buildPlaneBasis, projectPointsTo2D,
)

triangles = loadOBJ("model.obj")
normalized, center, scale = normalizeMesh(triangles)
plane_axis = (0.0, 0.0, 1.0)
triangle_ids, slice_points, plane_centers, segments = meshSlicing(
    normalized,
    plane_interval=0.05,
    plane_axis=plane_axis,
)
basis = buildPlaneBasis(torch.tensor(plane_axis, device=normalized.device))
  • Mesh loaders return triangle vertices with shape (faces, 3, 3) as float32 tensors on their selected device.
  • OFF/OBJ polygon faces are fan-triangulated; PLY support is ASCII only.
  • computeSDFImages expects padded 2D segment tensors with explicit valid counts and always returns its result on CPU.
  • The SDF rasterizer chunks slices and pixel rows to bound accelerator memory.

Optional dependencies

STL loading requires numpy-stl; 3D interactive figures require plotly; FLOP calculation requires calflops; TensorBoard logging requires TensorBoard. Imports from umbrella packages may expose optional modules, so install the dependencies used by your chosen workflow.
